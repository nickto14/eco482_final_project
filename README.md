Hello! This is my Final Research Project for ECO482 (Machine Learning for Macroeconomic Finance) taken in Winter 2026 at the University of Toronto. This report applies machine learning techniques to predict yield curve inversions in the U.S. economy. The yield curve is one of the most closely watched recession indicators in economics, having preceded every U.S. recession over the past 60 years.

In This Repository:

Report: A full write-up covering methodology, models, analysis, and results.

Code: All data cleaning, transformation, modeling, and evaluation scripts used in the analysis.

Data Appendix: Details on the Data Itself. and transformation codes applied to each variable.

A Brief Summary:

This project compares three models. A Random Walk baseline, a Random Forest Classifier, and a XGBoost Classifier. They are evaluated using metrics suited to imbalanced classification, including F1 score, ROC-AUC, and average precision. Both machine learning models modestly outperformed the Random Walk baseline in recall, with XGBoost emerging as the strongest overall performer.
